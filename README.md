## Why I make these

I work across content, websites, and software. The best ideas start with a task I have had to repeat or a step that left someone wondering what to do next. I build a small useful answer, test it in real use, and improve it from feedback.

**中文：** 我把真实工作中反复遇到的问题，做成能上手的小工具。这里放我的独立作品、公开实验和我参与的团队项目；每个项目都会注明是否可用、如何获取，以及谁维护它。

## Find the right place

- **Use a project:** open its website or repository above for the current version and instructions.
- **Report a problem:** open an issue in the relevant repository, with the version and steps to reproduce.
- **Explore team products:** visit the [BFTools product collection](https://github.com/mercedesbestsupplier-maker) for current team tools and release status.

I keep my independent work here. Products built with a team link to their own product and support pages, with credit to the people who build them.
