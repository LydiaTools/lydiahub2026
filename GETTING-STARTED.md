## Download labels

- **Live website:** Open it in a browser; no desktop installer is required.
- **Validation or experimental release:** A package is available, with platform and limitations described on its page.
- **Open-source toolkit:** Source and local setup steps are public; this does not imply a signed installer or hosted service.
- **Team product:** Open the [BFTools collection](https://github.com/mercedesbestsupplier-maker) for its own download status and support path.

If you hit a problem, use the issue tracker on that project's repository. Include the version, device, and steps to reproduce; leave out API keys and private customer data.
